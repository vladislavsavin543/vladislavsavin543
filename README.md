### [INCREMENT — лаборатория аплифта](https://github.com/vladislavsavin543/increment-uplift-lab)

**Задача:** определить, кому отправить письмо, чтобы получить дополнительные покупки
при ограниченном бюджете контактов.

Учебное исследование рандомизированного эксперимента Hillstrom:
**64 000 клиентов, два типа писем и контрольная группа**.

- SQL-витрина, проверка качества данных и баланса экспериментальных групп.
- Сравнение пяти стратегий рассылки при одинаковом бюджете контактов.
- Выбор аплифт-моделей на валидации и оценка через AIPW на отдельной тестовой выборке.
- Интерактивный калькулятор экономики кампании, отчёт и ноутбук на русском.
- Воспроизводимый анализ и автоматические проверки в GitHub Actions.

**Вывод:** преимущество выбранной персонализации при охвате 20% не подтвердилось.
Разница со случайной рассылкой — **−2,3 дополнительные покупки на 10 000 клиентов**,
95% доверительный интервал: **от −20,0 до +15,3**.
Результат показывает, почему сложность модели сама по себе не гарантирует пользу для бизнеса.
